# 市販リフィルの構成

このアプリが作れなければいけないものの一覧。**市販で用意されている組み方が
作れなければ、このアプリの意味はない**（ユーザーの判断）。KNOX・PLOTTER・
アシュフォード・能率（Bindex）・ダ・ヴィンチの売り場を見て集めたもの。

一覧そのものは「元の一覧」に、ユーザーがまとめたまま残す。その下の「軸に
分ける」「いまのアプリ」は、一覧を作る側の言葉に直したもの。

## 軸に分ける

一覧の項目は、ほとんどが次の5つの掛け合わせになっている。アプリはこの5つを
それぞれ持てばよく、項目を1つずつ作る必要はない。

| 軸 | 中身 | 一覧の例 |
|---|---|---|
| ① 1面に入れる期間 | 複数年・12/6/4/3/2/1か月・2週・1週・2日・1日・期間なし | 「6か月を1面」「2週間を1面」「2日を1面」 |
| ② 期間の描き方 | ブロック・縦型（リスト）・横型・時間軸（バーチカル）・ガント・タイムライン・トラッカー・表 | 「1か月ブロック」「1週間時間軸」「年間ガントチャート」 |
| ③ 添えるもの | メモ（無地・横罫・方眼・ドット）・ToDo・チェックリスト・目標・計画・振り返り・記録・家計簿・天気・タイトル | 「1週間＋振り返り」「月間＋家計簿」 |
| ④ 面の組み方 | 1面・見開き（左右同じ／違う）・表裏（同じ期間／別の期間／カレンダーとメモ）・折り・蛇腹 | 「表＝今年／裏＝翌年」「蛇腹1面1か月×12面」 |
| ⑤ 並び | 年間→月間→週間→日間→メモ、のつなぎ方 | 「年間→月間→週間」「月間→メモ」 |

## いまのアプリ（見込み。1つずつ作って確かめるまでは見込み）

| 軸 | できる | できない・足りない |
|---|---|---|
| ① 期間 | 1か月（マンスリー）、1〜14日（1日1面・2日・1週・2週。バーチカルは0〜24時まで）、年間カレンダー（1つに12・6・4・3・2か月。見開きで左右に分けて1年） | 年間計画表（月が列・日が行）、年間ガント、12か月の枠リスト、複数年 |
| ② 描き方 | ブロック、縦型（日付リスト）、横型（ホリゾンタル）、時間軸（バーチカル）、ガント（月）、ハビット（月） | 年間ガント、タイムライン、年間のトラッカー、表（記録系） |
| ③ 添えるもの | メモ（見出しつき＝タイトル付き）、罫線、方眼、TODO（チェック欄＝チェックリスト）、今月の目標、家計、写真 | ドット方眼のパーツ（紙の地にはある）、振り返り、天気、記録用の表（列見出しを書き換えられる表） |
| ④ 組み方 | 1面、見開き、蛇腹2面・3面、L字 | 表と裏に別のものを決める（表＝カレンダー／裏＝メモ、表＝今年／裏＝翌年）、4面以上の折り・蛇腹（A4で刷れる範囲の確認が要る） |
| ⑤ 並び | 1冊の中に並べる（年間がないので、月間→週間→メモまで） | 月ごとに交互にする組（パック。8章） |

## いまできないこと（月をまたぐ長さのほか）

1. **表と裏に別のものを決める。** 表＝カレンダー／裏＝メモ、表＝今年／裏＝
   翌年、表＝年間カレンダー／裏＝年間計画。いまは片面を両面で刷ると、次の
   ページがそのまま裏に来るだけ
2. **月ごとに月間と週間を交互にする組**（パック。フランクリン型）
3. **記録用の表。** 読書・映画・食事・睡眠・支出などの記録（一覧の8章の
   大半）は、列見出しを書き換えられる表があれば作れる。要求仕様9章で予定
   していて、まだ無い
4. **年間ガント・年間タイムライン・年間の習慣トラッカー**（月をまたぐ長さと
   一緒に作る）
5. **小さな欄**：天気、振り返り（いまは「目標」の枠で代用）、ドット方眼の
   パーツ（紙の地紋にはある）
6. **インデックス（タブ）。** 紙を切らないと作れない。代わりに、紙の端に
   月の印を刷る「印刷インデックス」ならできる
7. 4面以上の蛇腹（作らないと決めた）

近いが市販と違う:

- **セパレート式。** 市販は左に月〜木（4日）、右に金〜日（3日）。アプリが
  見開きで1週を割ると左3日・右4日になる（要求仕様7章「ノドをまたぐとき」）

## 決めたこと

- **蛇腹は今の3面まで。** 4面以上は紙（A4）の制約が大きい。一覧の「4つ折り」
  「6面・12面蛇腹」などは作らない
- **いちばん先に埋めるのは①の「月をまたぐ長さ」。** 市販でごく一般的なので、
  できないと困る。年間カレンダー（小さな月を並べる）・年間計画表（月が列、
  日が行）・年間ガント・複数月の月間を、サイズごとの読める／書ける大きさを
  確かめてから作る

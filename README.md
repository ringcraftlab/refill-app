# RingCraftLab

システム手帳のリフィルをスマホだけで作って、原寸PDFで印刷できるWebアプリ。

## このアプリが何なのか

市販のリフィルはほぼ良い。でも「メモ欄が狭い」「マンスリーをもう少し小さく」が変えられない。
紙は買ってきたものだから。**そこを自分で決められるようにする**のがこのアプリ。

目標は **Canvaより簡単**であること。Canvaは何でもできるが、そのぶん座標・レイヤー・
ハンドルがあって重い。このアプリには**座標がない**。

- **選ぶ**のはスタンプを押す感覚。トレイのパーツを指でつまんでページに落とすと、
  区画が自動で決まる。1個なら全面、2個なら上下、3個なら上＋下を左右、4個なら2×2。
- **調整**は指で自由に。パーツ同士の**境界線をドラッグすると連動して比率が変わる**
  （片方を広げるともう片方が縮む）。ここがこのアプリの存在理由。

開発者向けの設定パネルを横に常設するUIは**作らない**。設定はパーツをタップしたときだけ
下からシートで出す。

## 画面

1. **サイズ選択** — カードをタップした時点で次へ進む
2. **ページ構成** — 見開き（2ページ）か片面（1ページ）。見比べる時間が要るのでここだけ確定ボタン
3. **キャンバス編集** — 唯一の作業画面。キャンバスが主役

## セットアップ

```bash
npm install
npm run dev
```

## 見た目の確認

レイアウトを変えたら、コードを読んで判断せず**必ず描画して目で見る**。
推測ベースの修正を重ねると同じ不具合を何度も作ります。

```bash
npm run build
npx vite preview --port 4173 --strictPort &
npm run shots     # ./shots/ に操作手順ごとのPNGが出ます
```

`scripts/shoot.mjs` はスマホ幅で実際にアプリを操作します（サイズ選択 → 見開き →
マンスリー配置 → メモ追加 → 境界をドラッグしてメモを広げる）。

## マンスリーの4パターン

| 種別 | 内容 | ページの形 | リング位置 |
|---|---|---|---|
| 見開き・曜日分割 | 月火水を左、木金土日を右 | 縦・左右に並ぶ | 2ページの綴じ目 |
| 見開き・週分割 | 1〜2週目を1ページ、残りをもう1ページ | 横・上下に積む | 2ページの綴じ目 |
| 片側・縦 | 1ページに収まる7列 | 縦 | 側面 |
| 片側・横 | 片側・縦と中身は同一 | 横 | 上辺 |

**「横向き」はグリッドの中身を一切変えません。** 曜日は常に7列のままで、変わるのは
ページの形とリングの位置だけ。曜日と週を転置した表にしてはいけません。

横向きの実体は「穴が長辺にある縦長シートを90度回して読む」ことなので、画面上は
読む向き（横長・リングが上）で表示し、PDF出力時に物理シートへ回転して載せます。

## アーキテクチャ

```
src/
  App.tsx              3画面とキャンバス操作（ポインタイベント）
  types.ts             Layout スキーマ（version: 3）
  lib/
    layout.ts          mm幾何：リング帯の除外、区画分割、境界線
    parts.ts           各パーツを「与えられたmm矩形」に描く
    sizes.ts           リフィル寸法
    dates.ts           カレンダー生成・六曜
    draw.ts            描画プリミティブと配色
    render/
      pages.ts         layout + parts → 印刷可能なページ
      svg.tsx          画面プレビュー
      pdf.ts           pdf-lib で原寸出力
    storage.ts         localStorage 保存
```

パーツは「mm座標の描画プリミティブを返す純関数」。プレビューとPDFが同じプランを
消費するので、画面と印刷が構造的に一致します。CSS Grid で組まないので、行の高さが
ずれる・見出しが重なるといった不具合が起きません。

指でのドラッグは**ポインタイベント**で実装しています。HTML5のドラッグ&ドロップは
モバイルブラウザで動かないため使いません。

## 既知の制限

- **六曜は仮実装**。`(日付-1) % 6` で循環させているだけで、正しくは旧暦ベースの計算が必要。
  祝日データも未実装。
- PDF内フォントが Helvetica のため、**日本語が PDF に出ません**（画面には出ます）。
  `@pdf-lib/fontkit` + Noto Sans JP サブセットで対応予定。
- リング穴の位置・穴径は近似値。各サイズの実測表ができ次第 `lib/sizes.ts` を差し替え。
- 月の選択UIがない（データ上は `year`/`month` を持っており、現在の月を初期値にしている）。
- A5スリム・カスタムサイズ、両面編集、背景ガイド、オンボーディングは未実装。
- オフライン対応（PWA）は未組込み。

## データ互換性

`Layout.version` が `SCHEMA_VERSION`（現在 3）と一致しない保存データは読み捨てます。
version 1・2 は別のエディタのスキーマで、変換できません。
